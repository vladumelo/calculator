# Калькулятор покрытий — минималистичный single-screen UI

Интерфейс пересобран в стиле SaaS/CAD: минимум шума, крупный план в центре, только основные действия.

## Что удалено

- Убран громоздкий правый блок с постоянной таблицей покрытий.
- Убраны второстепенные кнопки и дублирующие панели.
- Из сметы убраны лишние колонки и редкие действия:
  - периметр,
  - № покрытия,
  - дублирование,
  - сброс.

## Что упрощено

- Верхняя панель: **Загрузить план**, **Задать масштаб**, **Покрытие**, **Экспорт**, мета-информация.
- Левая панель: только 4 инструмента:
  - Полигон,
  - Точки,
  - Панорама,
  - Удалить участок.
- Нижняя смета компактная, с ключевыми колонками и удалением одной кнопкой.

## Главный сценарий

1. Загрузить план.
2. Задать масштаб (2 точки + значение в метрах).
3. Выбрать покрытие.
4. Обвести участок (полигоном/по точкам).
5. Участок автоматически попадает в смету.
6. Отредактировать название, покрытие или цену при необходимости.

## Сохранённая логика

- zoom колесом мыши (в точку курсора);
- pan правой кнопкой мыши;
- рисование по точкам и свободной формой;
- расчёт площади и стоимости;
- выбор/удаление участка;
- редактируемая смета.

## Локальный запуск

```bash
cd /workspace/calculator
python3 -m http.server 8000
```
Открыть `http://localhost:8000`.
