# Калькулятор покрытий по изображению

Приложение разделено на 2 интерфейсных режима:

1. **Основная страница** — загрузка файла, покрытия, смета.
2. **Fullscreen-редактор** — все инструменты рисования/масштаба/навигации.

## Структура файлов

- `index.html` — main page + отдельный fullscreen overlay-редактор.
- `styles.css` — чистая карточная верстка main page и отдельные стили editor overlay.
- `app.js` — логика: состояние, viewport/координаты, рисование, смета, материалы, editor UI.

## Что теперь на основной странице

- загрузка изображения;
- кнопка «Открыть план в редакторе»;
- блок покрытий (таблица + добавление покрытия);
- таблица сметы по участкам.

На основной странице **нет** инструментов zoom/pan/draw.

## Что теперь внутри fullscreen editor

- большой canvas с изображением;
- режимы: Рисование / Масштаб / Рука / Выбор;
- команды контура: отмена точки, очистка, замыкание, удаление выбранного участка;
- навигация: zoom in/out, 100%, вписать, сбросить;
- статусная панель: масштаб, zoom %, координаты курсора;
- кнопка закрытия редактора и кнопка сворачивания панели инструментов.

## Как исправлена проблема «слипшихся кнопок»

- Инструменты вынесены в отдельную вертикальную панель editor overlay.
- Кнопки сгруппированы по смыслу в секции с заголовками.
- Добавлены отступы и `gap` между элементами.
- Основная страница разгружена и состоит из аккуратных карточек.

## Система координат

- Полигоны хранятся в координатах изображения.
- Для viewport используются `zoom`, `offsetX`, `offsetY`.
- Преобразования:
  - `client -> canvas` через `getBoundingClientRect()`;
  - `canvas -> image` для кликов;
  - `image -> canvas` для отрисовки.
- Canvas синхронизируется с `devicePixelRatio` для HiDPI.

## Локальный запуск

### Вариант 1
Открыть `index.html` в браузере.

### Вариант 2 (рекомендуется)
```bash
cd /workspace/calculator
python3 -m http.server 8000
```
Открыть `http://localhost:8000`.
