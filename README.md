# Калькулятор покрытий — улучшенный UX рисования и масштаба

Интерфейс доработан без поломки расчётов: стало понятнее рисовать полигон и задавать масштаб.

## Что обновлено

- Добавлены кнопки в тулбар:
  - **Undo point (↩️)** — отмена последней точки;
  - **Clear polygon (🧹)** — удаление текущего незавершённого полигона;
  - **Scale tool (📏)** — отдельный инструмент калибровки масштаба.
- Масштаб вынесен в явный режим:
  1) включить Scale tool;
  2) выбрать 2 точки;
  3) ввести реальное расстояние в метрах;
  4) применить — режим автоматически завершается.
- UX рисования улучшен:
  - отображаются текущие линии;
  - последняя точка выделена сильнее;
  - показывается временная линия до курсора;
  - завершение полигона по двойному клику (в режиме точек).
- Сохранены: загрузка плана, расчет площади, таблица сметы, экспорт, pan/zoom.

## Добавленные функции

- `undoPoint()`
- `clearCurrentPolygon()`
- `startScaleTool()`
