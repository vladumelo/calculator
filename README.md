# Планировщик покрытий по изображению

Минимальное веб-приложение на чистом HTML/CSS/JS для обрисовки участков на плане и автоматического расчёта площади, периметра и сметы.

## Структура файлов

- `index.html` — интерфейс: загрузка изображения, режимы, управление контурами, покрытия, смета.
- `styles.css` — минимальные стили и адаптивная сетка.
- `app.js` — данные, геометрия, рендер canvas и таблиц, обработчики событий.

## Функции

- загрузка изображения плана;
- задание масштаба по 2 точкам + реальная дистанция в метрах;
- расчёт коэффициента `px → m` и `px² → m²`;
- обрисовка контуров (точки, линии, замыкание);
- удаление последней точки и очистка текущего контура;
- список предустановленных покрытий: Асфальт, Бетон, Газон, Брусчатка;
- добавление своего покрытия (номер, название, цвет, цена за м²);
- расчёт площади (shoelace), периметра и стоимости каждого участка;
- таблица сметы по участкам с удалением участка и итогом.

## Как запустить локально

### Вариант 1 (без сервера)

Откройте `index.html` в браузере двойным кликом.

### Вариант 2 (рекомендуется)

```bash
cd /workspace/calculator
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.

## Ключевой технический момент про координаты клика

Координаты хранятся в **координатах изображения** (natural pixels), а не в экранных.
Преобразование клика выполняется через `getBoundingClientRect()` и внутренний размер изображения:

- `x_img = (clientX - rect.left) * imageWidth / rect.width`
- `y_img = (clientY - rect.top) * imageHeight / rect.height`

Это устраняет смещение при CSS-масштабе, скролле, адаптиве и HiDPI.
