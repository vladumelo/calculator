# Калькулятор покрытий по изображению

Новая версия работает **на одном экране**: без отдельного окна и fullscreen-модалки.

## Структура файлов

- `index.html` — единый экран: слева инструменты, в центре изображение+canvas, справа покрытия/инфо, снизу смета.
- `styles.css` — grid-layout, визуальные группы инструментов, адаптивность и аккуратные отступы.
- `app.js` — логика приложения, разделённая на блоки:
  - состояние приложения и viewport;
  - трансформации координат;
  - рендер canvas;
  - рисование по точкам;
  - свободное рисование (freehand);
  - расчёт сметы;
  - управление покрытиями;
  - обработчики UI.

## Единый экран (новая концепция)

Пользователь одновременно видит:
- изображение плана и результат отрисовки;
- инструменты и режимы;
- список покрытий;
- таблицу сметы.

Никаких overlay / fullscreen editor больше нет.

## Как работает pan

- ПКМ (удержание) в области canvas — временный pan (перемещение вида).
- Панорамирование работает при любом режиме.
- ПКМ не ставит точки и не рисует.
- Space (удержание) или режим «Рука» также включают pan.

## Как работает рисование по точкам

- Режим **«Точки»**.
- ЛКМ добавляет вершины в координатах изображения.
- Кнопка «Замкнуть контур» (или Enter) создаёт участок и добавляет его в смету.
- Валидация: минимум 3 точки, нужен масштаб.

## Как работает свободная форма

- Режим **«Свободная форма»**.
- Пользователь зажимает ЛКМ и ведёт мышь.
- Траектория записывается в координатах изображения.
- При отпускании ЛКМ контур автоматически завершается и добавляется как участок.
- Добавлено упрощение: очень близкие точки пропускаются (`minDistanceImagePx`).

## UX-улучшения

- Инструменты сгруппированы: файл/покрытие, режимы, контур, вид.
- Активный режим визуально выделяется.
- Статус-строка показывает текущий режим и подсказки управления.
- Подсветка выбранного участка в canvas и связанной строки в смете.
- Таблица сметы остаётся редактируемой (покрытие, цена, площадь, периметр, дублирование, сброс, удаление).

## Технические детали координат

- Все контуры хранятся в координатах изображения.
- Viewport хранится отдельно: `zoom`, `offsetX`, `offsetY`.
- Преобразования:
  - `client -> canvas` через `getBoundingClientRect()`;
  - `canvas -> image` для кликов;
  - `image -> canvas` для отрисовки.
- Canvas синхронизируется с `devicePixelRatio` (HiDPI).

## Локальный запуск

### Быстро
Открыть `index.html` в браузере.

### Рекомендуется
```bash
cd /workspace/calculator
python3 -m http.server 8000
```
Открыть `http://localhost:8000`.
