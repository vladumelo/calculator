# Калькулятор покрытий по изображению

Интерфейс переработан под работу **без прокрутки страницы** в основном desktop-сценарии: один экран, большая зона плана, компактные инструменты и смета в фиксированной нижней панели.

## Что изменено в структуре UI

- Убран отдельный правый постоянный блок **«Покрытия»**.
- Функционал покрытий перенесён в левую панель в сворачиваемый блок **«Настройки покрытий»** (`details`).
- На виду оставлен только выбор **«Текущее покрытие»** для рисования.
- Основная компоновка:
  - верх: заголовок + строка статуса;
  - середина: слева инструменты, по центру большое изображение/canvas;
  - низ: компактная смета фиксированной высоты с внутренним скроллом.

## Файлы проекта

- `index.html` — единый экран: инструменты + canvas + нижняя смета.
- `styles.css` — layout на `100vh`, локальные scroll-контейнеры, компактный user-friendly стиль.
- `app.js` — логика рисования, zoom/pan, freehand, масштаб, смета, покрытия.

## Как решена проблема прокрутки страницы

- `html, body` фиксированы по высоте: `height: 100%`, `overflow: hidden`.
- Главный контейнер `.app` занимает `100vh` и делится на 3 ряда (`header`, `workspace`, `estimate`).
- Вертикальный скролл разрешён только внутри:
  - левой панели инструментов (`.tools`),
  - панели сметы (`.estimate-scroll`),
  - сворачиваемых настроек покрытий.

## Что сохранено по функционалу

- загрузка изображения;
- масштаб по 2 точкам;
- zoom кнопками и колесом (в точку курсора);
- pan правой кнопкой мыши;
- рисование по точкам;
- свободная форма (freehand) с упрощением траектории;
- выбор и удаление участков;
- редактируемая смета;
- связь участков с покрытиями.

## Локальный запуск

### Быстро
Открыть `index.html` в браузере.

### Рекомендуется
```bash
cd /workspace/calculator
python3 -m http.server 8000
```
Открыть `http://localhost:8000`.
