# Онлайн-калькулятор покрытий

Простое веб-приложение для сметного расчета покрытий из проекта благоустройства.

## Что умеет

- загружать типы покрытий из JSON-файла проекта;
- формировать строку по каждому покрытию;
- менять количество, единицу измерения и стоимость;
- переходить в детальную смету по слоям конструкции покрытия;
- автоматически пересчитывать общую стоимость.

## Как запустить (инструкция для новичка)

Есть два простых способа.

### Способ 1 — самый быстрый (без установки программ)

1. Откройте папку проекта `/workspace/calculator`.
2. Найдите файл `index.html`.
3. Дважды кликните по `index.html` — файл откроется в браузере.

Готово: калькулятор уже работает.

---

### Способ 2 — через локальный сервер (рекомендуется)

Этот способ ближе к «настоящему запуску сайта» и надежнее в разных браузерах.

#### Шаг 1. Убедитесь, что установлен Python

В терминале выполните:

```bash
python3 --version
```

Если видите версию (например, `Python 3.10.12`) — всё хорошо.

#### Шаг 2. Перейдите в папку проекта

```bash
cd /workspace/calculator
```

#### Шаг 3. Запустите локальный сервер

```bash
python3 -m http.server 8000
```

После этого в терминале появится сообщение, что сервер запущен.

#### Шаг 4. Откройте приложение в браузере

Перейдите по адресу:

```text
http://localhost:8000
```

#### Шаг 5. Как остановить сервер

Вернитесь в терминал и нажмите:

```text
Ctrl + C
```

---

## Как пользоваться приложением

1. Нажмите **«Загрузить демо-проект»**, чтобы увидеть пример.
2. Либо загрузите свой JSON через поле **«JSON проекта»**.
3. В таблице изменяйте:
   - количество;
   - единицу измерения;
   - цену за единицу.
4. Нажмите **«Открыть»** в строке покрытия, чтобы перейти к расчету по слоям.
5. В детализации слоев также можно менять количество, единицы и цены.
6. Сумма покрытия и общая стоимость пересчитаются автоматически.

## Формат JSON проекта

```json
{
  "name": "Название проекта",
  "coverages": [
    {
      "code": "1",
      "name": "Асфальтобетон",
      "quantity": 1637,
      "unit": "m2",
      "unitPrice": 1650,
      "layers": [
        {
          "name": "Уплотнение грунта",
          "quantity": 1637,
          "unit": "m2",
          "unitPrice": 85
        }
      ]
    }
  ]
}
```

Поддерживаемые единицы: `m2`, `m3`, `pcs`.

## Что делать, если не открывается

- Проверьте, что запускаете именно `index.html`.
- Если браузер показывает пустую страницу — используйте запуск через сервер (Способ 2).
- Если не работает `python3`, установите Python и повторите шаги выше.
