# Калькулятор покрытий по изображению

Приложение на чистом HTML/CSS/JS для точной обрисовки участков на плане с масштабом, zoom/pan/fullscreen и редактируемой сметой.

## Файлы проекта

- `index.html` — структура UI: боковая панель инструментов, холст, таблица сметы.
- `styles.css` — стили панели, холста, таблиц, состояний active/hover/manual.
- `app.js` — логика, разделённая по блокам:
  - state / данные,
  - viewport (zoom/pan/transform),
  - canvas rendering,
  - polygon editing,
  - estimate table editing,
  - materials management,
  - UI controls.

## Как реализованы zoom / pan / fullscreen

- В `state.viewport` хранятся `zoom`, `offsetX`, `offsetY`.
- Все полигоны хранятся только в координатах изображения.
- Рендер в canvas выполняется через преобразование `image -> canvas`.
- Обратное преобразование клика: `client -> canvas -> image`.
- В fullscreen вызывается `requestFullscreen()` для блока редактора, после чего пересчитывается размер canvas.

## Система координат (устойчивая)

- `clientToCanvas()` использует `getBoundingClientRect()`.
- `canvasToImage()` учитывает текущие `zoom/offset`.
- `imageToCanvas()` используется для отрисовки точек и полигонов.
- Размер внутреннего буфера canvas синхронизируется с CSS-размером и `devicePixelRatio` (HiDPI).

## Причина старого бага со смещением точки

Баг был из-за смешивания координат разных пространств (client/CSS/canvas/image) без корректного преобразования через `getBoundingClientRect()`, `zoom`, `offset` и DPR. В результате точка ставилась со смещением при адаптиве, скролле, масштабировании страницы или изменении размеров холста.

## Что переработано по сравнению со старой версией

- Переписан canvas-движок с явным viewport-transform.
- Переписана таблица сметы: теперь полноценное inline-редактирование строки.
- Добавлены выбор/подсветка участка ↔ строки.
- Добавлены fullscreen, zoom, pan и горячие клавиши.

## Горячие клавиши

- `Delete` / `Backspace` — удалить последнюю точку
- `Enter` — замкнуть контур
- `Esc` — очистить контур
- `+` / `-` — zoom
- `F` — fullscreen
- `Space` (удерживать) — pan
